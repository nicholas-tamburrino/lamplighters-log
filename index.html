The Lamplighter's Log

A lighthouse mystery. The lamp is dark and a ship is coming.

Narrator: scripted (default) or a model

The game works fully offline with the written text. Optionally a model can rewrite what you see. The game engine decides what is true; a rule-based guard throws out any model text that invents objects or exits, and the game falls back to the written text. Keys stay in this page's memory and are never saved.

Ollama needs OLLAMA_ORIGINS set to allow this page's address. Model replies: 0 accepted, 0 rejected.
